# Language packs 2026.11.08.1

All six interface packs — Croatian, English, German, Spanish, French and Italian — contain **4,816 keys**. The revision adds translations for personal work lists, recent contributions, drafts, publication review, list paging, Workspace search filters and the account menu. Draft and review status labels are corrected where needed.

The catalogue advertises the new independent pack revision and verifies each file by SHA-256. Pack format remains version 2, Croatian remains the canonical lookup key, and the existing language names, flags, placeholders and legacy keys are retained.

Catalogue validation checks completeness and placeholders in all six packs. Source validation covers the current Simbioza application and optional modules; the compatibility CI also checks published Simbioza 0.3.17, 0.3.32 and 0.3.44 baselines. Installing a pack does not enable a module or change access rights.

Applications continue to offer only installed and enabled interface languages. Updating this repository does not automatically install additional languages in an existing application.
